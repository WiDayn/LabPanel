## FRP 工作原理

FRP (Fast Reverse Proxy) 是一个高性能的反向代理应用，用于将内网服务暴露到公网。

### 基本架构

```
内网服务器，本机 (frpc)  ←→  公网服务器 (frps)  ←→  公网用户
```

1. **frps (服务端)**：运行在具有公网 IP 的服务器上，监听来自 frpc 的连接
2. **frpc (客户端)**：运行在内网服务器上，主动连接到 frps
3. **反向代理**：frps 将公网请求转发到内网 frpc，frpc 再将请求转发到本地服务

### 工作流程

1. frpc 启动后，主动与 frps 建立 TCP 连接（通常使用长连接）
2. 用户通过公网 IP 和端口访问服务
3. frps 接收请求，通过已建立的连接转发给对应的 frpc
4. frpc 将请求转发到本地服务（如 SSH、Web 服务等）
5. 响应数据按相反路径返回给用户

### 优势

- **无需公网 IP**：内网服务器无需公网 IP 即可提供服务
- **安全性**：内网服务器不直接暴露在公网
- **灵活性**：可以映射多个服务到不同的端口

## 创建容器并映射 SSH 到公网

### 步骤 1：创建 LXC 容器

在 LabPanel 的 LXC 容器管理页面：

1. 点击"新增容器"按钮
2. 输入容器名称（例如：`my-server`）
3. 设置 root 密码
4. 点击"创建"

系统会自动执行以下操作：
- 创建 Ubuntu 22.04 容器
- 启用 NVIDIA 运行时支持
- 添加 GPU 设备
- 配置 SSH 服务（允许 root 登录和密码认证）

### 步骤 2：配置 FRP 代理映射

在 LabPanel 的 FRP 配置管理页面：

1. 点击"新增代理"按钮
2. 填写代理信息：
   - **名称**：`ssh-my-server`（自定义名称）
   - **类型**：`tcp`
   - **本地IP**：容器的 IP 地址（可通过 `lxc list` 查看）
   - **本地端口**：`22`（SSH 默认端口）
   - **远程端口**：选择一个未被占用的端口（例如：`2222`）
   - **备注**：`SSH 映射到 my-server 容器`
3. 点击"保存"

### 步骤 3：连接 SSH

配置保存后，系统会自动验证并热重载配置。连接方式：

```bash
ssh root@<公网服务器IP> -p <远程端口>
```

例如：
```bash
ssh root@123.45.67.89 -p 2222
```

### 示例配置

假设：
- 公网服务器 IP：`123.45.67.89`
- 容器名称：`my-server`
- 容器 IP：`10.0.0.100`
- 远程端口：`2222`

FRP 代理配置：
- 名称：`ssh-my-server`
- 类型：`tcp`
- 本地IP：`10.0.0.100`
- 本地端口：`22`
- 远程端口：`2222`

连接命令：
```bash
ssh root@123.45.67.89 -p 2222
```

输入创建容器时设置的 root 密码即可登录。
